# Installation

## Using pip

1. Run the following command in your terminal:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Copy the example configuration file:

   ```bash
   cp config.example.yaml config.yml
   ```

# If Indonesian TTS Voice Is Not Available on Windows

## How to Add Indonesian Language and Enable TTS Voice:

1. Open **Settings** > **Time & Language** > **Language & Region**
2. Click **Add a language**, then search for and add **Indonesian**
3. After adding, go to **Speech** settings
4. Click **Add voices**
5. Find and select **Indonesian**, then click **Install**
6. Once installed, locate the file `clone_voices.ps1`
7. Right-click the file and choose **Run as Administrator**
